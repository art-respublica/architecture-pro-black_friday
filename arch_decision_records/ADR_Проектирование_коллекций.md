### <a name="_qmphm5d6rvi3"></a>**Решение**

Предлагается добавить коллекции:
* /orders - коллекция заказов 

Состав полей:
1. id - уникальный идентификатор заказа
2. user_id - идентификатор пользователя
3. created_at - дата и время оформления заказа
4. status - статус заказа. Возможные значения ограничены перечислением: new, paid, received, cancel, refund
5. total_amount - общая сумма заказа
6. geozone - гео-зона заказа
7. items - список позиция заказа
   1. product_id - идентификатор товара
   2. category_id - категория товара (справочно)
   3. quantity - количество товаров в заказе
   4. price - цена товара

Элемент коллекции
````json
{
  "id": "0cf9aeed-3ebb-47ab-8108-72424d9cb8e2",
  "user_id": "969ba334-f6fe-4176-a06b-be3cb231eefa",
  "created_at": "2026-02-19 20:00:00",
  "status": "new",
  "total_amount": 256.34,
  "geozone": "msc",
  "items": [
    {
      "product_id": "a6ecfc37-e0c9-4d3b-abc4-a636d3d87bc7",
      "category_id": "55b85118-7d05-4dd8-8b71-f8b403dc9527", 
      "quantity": 1,
      "price": 100
    }
  ]
}
````
Шардирование заказов осуществляется по гео-зонам. Вероятность, что один пользователь будет делать заказы только в одной гео-зоне, чрезвычайно высокая.
Внутри шарда по гео-зонам предлагается разделять данные с помощью хэшированного шардирования по ключу user_id. С целью получить заказы одного пользователя вместе в одном шарде.

Доступные операции:
POST  /users/{user_id}/orders - создание заказа. Доступно только авторизованным пользователям
GET   /users/{user_id}/orders - получение списка заказов пользователя
GET   /users/{user_id}/orders/{order_id} - получения данных конкретного заказа пользователя, в том числе и его статуса
PATCH /users/{user_id}/orders/{order_id} - отмена заказа
Гео-зона передается в качестве общего параметра запроса `?geozone=msc` или в качестве поля тела запроса

* /products - коллекция заказов

Состав полей:
1. id - уникальный идентификатор товара
2. category_id - идентификатор категории
3. name - наименование товар
4. attributes - дополнительные атрибуты товара. Расширяемая коллекция полей, включает цвет, размер и т.п.
5. price - актуальная цена товара
6. total_available - актуальный общий остаток товара
7. goods - остатки товаров в каждой гео-зоне
   1. geozone - гео-зона
   2. available - остаток товара в гео-зоне

Элемент коллекции товаров
````json
{
  "id": "a6ecfc37-e0c9-4d3b-abc4-a636d3d87bc7",
  "category_id": "55b85118-7d05-4dd8-8b71-f8b403dc9527",
  "name": "Мобильный телефон Samsung S25 FE",
  "price": 56245.34,
  "attributes": {
    "colour": "white",
    "size": "M"
  },
  "total_available": 16,
  "remaining": [
    {
      "geozone": "Moscow",
      "available": 15
    },
    {
      "geozone": "Pskov",
      "available": 1
    }
  ]
}
````
Разделения товаров по шардам осуществляется с помощью диапазонного шардирования по категориям. С целью быстрого получения товаров одной категории из одного шарда.
При возникновении потребности внутри шарда по категориям предлагается разделять данные с помощью хэшированного шардирования по ключу product_id. 

Доступные операции:
PUT /products - обновление остатков товаров. В теле запроса передается список товаров, их категорий, и изменение по гео-зонам
GET /products?category=55b85118-7d05-4dd8-8b71-f8b403dc9527 - получение списка товаров по категории
GET /products?category=55b85118-7d05-4dd8-8b71-f8b403dc9527&from=100&to=1000 - получения списка товаров по категории с фильтром по диапазону цен
GET /products/{product_id}?category=55b85118-7d05-4dd8-8b71-f8b403dc9527 - получения описания конкретного товара категории

* /carts - коллекция корзин

Состав полей:
1. id - уникальный идентификатор корзины
2. user_id - идентификатор пользователя
3. session_id - идентификатор сессии неавторизованного пользователя, не указывается, если указан user_id
4. status - статус корзины. Возможные значения ограничены перечислением: active, ordered, abandoned
5. created_at - дата и время создания корзины
6. updated_at - дата и время обновления корзины
7. expires_at - дата и время удаления корзины для автоматической очистки
8. items - список позиция заказа
    1. product_id - идентификатор товара
    2. category_id - категория товара (справочно)
    3. quantity - количество товаров в корзине

Элемент коллекции корзин
````json
{
  "id": "5ea30df3-a003-4c1e-b966-045fc4bf807c",
  "user_id": "969ba334-f6fe-4176-a06b-be3cb231eefa",
  "session_id": null,
  "status": "active",
  "created_at": "2026-02-19 20:00:00",
  "updated_at": "2026-02-19 20:00:01",
  "expires_at": "2026-02-28 20:00:00",
  "items": [
    {
      "product_id": "a6ecfc37-e0c9-4d3b-abc4-a636d3d87bc7",
      "category_id": "55b85118-7d05-4dd8-8b71-f8b403dc9527",
      "quantity": 1
    }
  ]
}
````

Разделения корзин по шардам осуществляется с помощью хэшированного шардирования по user_id и session_id. Для равномерного распределения данных по шардам.

Доступные операции:
POST   /users/{user_id}/carts - создание корзины. Неавторизованным пользователям корзина создается при начале новой сессии. Авторизованным - один раз при авторизации
PUT    /users/{user_id}/carts - добавление товара в корзину. Корзина становится активной
DELETE /users/{user_id}/carts - удаления товара из корзины
GET    /users/{user_id}/carts - получения данных корзины пользователя
GET    /session/{session_id}/carts - получения данных гостевой корзины
PATCH  /users/{user_id}/carts - отметка корзины пользователя как заказанной
PATCH  /session/{session_id}/carts - отметка гостевой корзины как брошенной
PUT    /session/{session_id}/to/users/{user_id} - слияние гостевой корзины в пользовательскую
